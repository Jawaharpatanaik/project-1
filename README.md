# 🏀 Nike Landing Page

A modern and responsive landing page for Nike built using **Tailwind CSS** and **Vite**. This project showcases a stylish frontend with smooth development experience.

---

# 🚀 Features

- Fully responsive design  
- Clean UI using Tailwind CSS  
- Fast development with Vite  
- Modular and organized folder structure

---

# 📁 Folder Structure



LandingPageNike-main/
├── public/ # Static files
├── src/ # Main codebase (components, CSS, JS)
├── index.html # Main HTML file
├── tailwind.config.js # Tailwind configuration
├── postcss.config.js # PostCSS setup
├── vite.config.js # Vite setup
├── package.json # Project info and dependencies
